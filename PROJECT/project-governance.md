# Elmira Sleep — Project Governance

## Purpose
This repository is the controlled documentation and implementation history for the Elmira Sleep Zoho CRM and Zoho Desk project.

## Status Model
- PROPOSED — design under discussion
- APPROVED — explicitly confirmed as final
- IN CONFIGURATION — currently being built
- LIVE — configured and verified in CRM
- SUPERSEDED — replaced by a later approved version
- ARCHIVED — historical reference only

## Working Rules
1. Separate proposed design from live CRM configuration.
2. Record material decisions and their dates.
3. Preserve historical versions rather than silently overwriting decisions.
4. Use meaningful commits for material project changes.
5. Capture CRM screenshots as configuration evidence when supplied.
6. Do not mark a design APPROVED or LIVE without explicit confirmation/evidence.

## Current Repository Baseline
- Default branch: main
- Repository status at project-structure audit: initial repository with README only.
- Current implementation evidence is maintained separately in the CRM snapshot and project source documents until incorporated into the repository.
